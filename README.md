# Lumière Beauty Studio: Salon Website + Chatbot

Next.js 14 + Tailwind salon website with a rule-based (no-LLM) chatbot and WhatsApp enquiry flow.
Edit `config/site.ts` to rebrand.

## One-click deploy

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/varunmulay-droid/Salonsite)

The button reads `render.yaml` (Blueprint) and creates the web service automatically.

## Local

```bash
npm install
npm run dev
```
